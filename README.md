# بوابة النماذج الإلكترونية - مصنع المنار للبلاستيك
### Electronic Forms Portal & Dynamic Dashboard

بوابة ويب مخصصة مبنية باستخدام **PHP** و **Tailwind CSS** لإدارة واستعراض وطباعة النماذج والمستندات التشغيلية لمصنع المنار للبلاستيك، مع دعم كامل للغة العربية واتجاه اليمين إلى اليسار (RTL).

---

## 🌟 المميزات الرئيسية

- **فحص ديناميكي تلقائي (Dynamic PHP Scanner):** قراءة تلقائية لكافة النماذج المضافة إلى مجلد `forms/` (ملفات `.html` و `.php`) واستخراج العناوين وتواريخ التعديل وأحجام الملفات دون أي تعديل يدوي في كود البوابة.
- **واجهة عصرية بتصميم بطاقات (Card Grid):** بطاقات تعرض كود النموذج، تصنيفه، تاريخ التحديث، وحجم الملف مع مؤثرات بصرية وتوافق تام مع مختلف الشاشات.
- **بحث فوري (Live Instant Search):** فلترة لحظية باستخدام JavaScript للاسم، الكود التعريفي، أو التصنيف مع زر مسح سريع واختصار لوحة المفاتيح (`/`).
- **فلترة وتصنيف ذكي (Category Filters):** تصنيف آلي للنماذج (المشتريات، الموارد البشرية، الإنتاج، الجودة، المستودعات) مع إمكانية الفرز حسب الأحدث، الأقدم، الاسم أو الحجم.
- **إجراءات مباشرة:**
  - زر **معاينة / فتح** في تبويب مستقل (`target="_blank"`).
  - زر **تحميل مباشر** للملف (`download`).
  - زر **نسخ الرابط المباشر** للنموذج مع إشعار توست تفاعلي.
- **حماية كاملة (.htaccess):** منع استعراض المجلدات (`Options -Indexes`) وحماية الملفات الحساسة وترويس الأمان (Security Headers) المتوافقة مع خوادم الاستضافة مثل Hostinger (Apache / LiteSpeed).

## 📁 هيكلية المشروع (Directory Structure)

```text
factory-forms/
├── .htaccess                     # إعدادات الحماية ومنع استعراض المجلدات
├── README.md                     # التوثيق الرسمي للمشروع
├── index.php                     # البوابة الرئيسية وكود الفحص والعرض التفاعلي
└── forms/                        # مجلد النماذج والمستندات
    ├── .htaccess                 # حماية إضافية لمجلد النماذج
    ├── PR-2026-0042.html         # نموذج طلب شراء داخلي (مشتريات)
    └── HR-attendance-salary-card.html # بطاقة رواتب وحضور وانصراف (موارد بشرية)
```

## 🚀 كيفية إضافة نماذج جديدة في المستقبل

لإضافة أي نموذج جديد:
1. قم بوضع ملف الـ HTML أو PHP داخل مجلد `forms/`.
2. احرص على تسمية الملف بحروف إنجليزية وأرقام وشرطات (مثل: `PR-2026-0043.html` أو `QC-report.html`).
3. سيقوم النظام فوراً بالتعرف عليه، استخراج عنوانه تلقائياً من وسم `<title>`، تصنيفه، وعرضه في الواجهة والبحث دون الحاجة لأي برمجة إضافية!

---

## 🌐 النشر والاستضافة على Hostinger

المشروع جاهز تماماً للرفع إلى خوادم الاستضافة:
- عبر **Git Deployment** في لوحة تحكم Hostinger (hPanel): ربط المستودع بالفرع `main`.
- أو عبر **File Manager / FTP**: رفع محتويات المستودع مباشرة داخل مجلد `public_html`.
